# Writing Guidelines

These notes consolidate the advisor's writing instructions and the local
rules for this thesis.

## Global Rules

- Write the thesis in English.
- Do not mention more open problems than the thesis actually addresses.
- Every figure used in the manuscript must be explicitly mentioned in the
  surrounding text.
- Use DBLP as the primary BibTeX source. Use Google Scholar only when DBLP
  does not provide a usable entry.
- Do not put raw URLs in bibliography entries when avoidable. Put web links in
  footnotes if they are useful for reproducibility or software references.
- Prefer clear claims over broad claims. If an experiment is a pilot or smoke
  test, call it that explicitly.
- Keep the previous thesis `tesi_t_simoneMazzacano/` as the main style and
  structure reference, but adapt the content to this project.

## Abstract

- Target length: about 250 words.
- No bibliography citations and no pointers to other sections.
- Structure:
  1. Context.
  2. Motivation or open problem.
  3. What this thesis does to address that problem.
  4. One compact sentence summarizing the method.
  5. Short experimental setup mention.
  6. Main results.
- The method should be introduced with one sentence that summarizes the full
  approach, followed by additional detail if needed.

## Introduction

- Target length: about two pages.
- It should be an expanded version of the abstract, but without the final
  conclusions.
- It must close with an outline of the thesis chapters.

## Chapter Structure

- Chapter 1: theory/background. It should cover only what the reader needs for
  the later chapters. Target length around ten pages and at least two sections.
- Chapter 2: related work. One section or subsection per relevant line of work
  or key paper group. Target length around five pages. It must show what prior
  work did and what this thesis does differently.
- Chapter 3: method. Start with preliminaries that clarify the task. Include at
  least one original figure, not generated by AI. Export diagrams as PDF when
  possible.
- Chapter 4: experimental setup. Include implementation details, libraries,
  models, why those models were used, datasets, metrics, cluster environment,
  hyperparameters, baselines, and prompts if useful.
- Chapter 5: results. Include all obtained results in the clearest format:
  baseline comparisons, ablations, and efficiency numbers.
- Chapter 6: conclusions and future work.
- Final acknowledgments: thank Prof. Moro first.

## Experimental Writing Checklist

- For each dataset, explain why it is used and how examples are structured.
- For each metric, define the range/boundary and how to interpret higher or
  lower values.
- For each model, explain the role it plays: evaluated judge, proposer,
  auxiliary judge, or NLA/perplexity source.
- Include a hyperparameter table with values tried. Mark the final selected
  value with an asterisk.
- Make clear what each result is compared against.
- Distinguish paper-aligned results from diagnostic/smoke runs.

Keywords are the ones that will be submitted on Alma Tesi. Candidate keywords
